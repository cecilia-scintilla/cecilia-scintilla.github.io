Bugku CTF - 把猪困在猪圈里 Writeup

一、题目信息

- 题型：Crypto（密码学）
- 题目：把猪困在猪圈里
- 考点：base64 → 图片的还原、猪圈密码（Pigpen Cipher）识别与对照解码

二、题目分析

- 下载附件，打开是一大段看起来像 base64 的文本（字母数字加 `+/=`，还有换行）。
- 题目名字是**最直接的提示**："猪圈"两个字直接指向 **猪圈密码**（Pigpen Cipher，也叫共济会密码）。
- 这里有个关键判断：这段 base64 **直接解码得到的不是可读文本**，而是一堆乱码。遇到这种情况要想到：base64 不只是用来编文本的，它也可以编码**图片等二进制文件**。
- 所以正确思路是两步：

```text
第 1 步：base64 -> 图片（把附件还原成图片文件）
第 2 步：图片里画的正是猪圈密码符号，对照密码表翻译成字母
```

三、解题步骤

- **第一步：把 base64 还原成图片**
  - 在线工具：`https://www.lddgo.net/convert/base64-to-image`，或"随波逐流"里的"图片 - base64 转图片"；
  - 也可以自己写一行（把附件内容存成 `a.txt`）：
  - 小技巧：如果懒得判断文件类型，还原出来直接改后缀为 `.png` 一般就能看（真正的文件头是 `89 50 4E 47`）。

- **第二步：识别猪圈密码**
  打开图片会看到一串由**几何图形**组成的符号：有"井字格的某一块"、有"X 形交叉分出的三角形"，部分图形里还带小圆点 —— 这就是标准的猪圈密码。

- **第三步：对照密码表翻译**
  猪圈密码的规则其实很好记，只有两条：

```text
① 看形状属于哪一类：
   井字格（9 个位置）  ->  依次对应 A~I
   X 形格（4 个三角形）->  依次对应 S~V
② 再看有没有"点"：
   不带点  ->  A~I / S~V
   带一个点 ->  J~R / W~Z
```

  完整对照表：

```text
  井字格（无点）= A B C / D E F / G H I
      ┌───┬───┬───┐
      │ A │ B │ C │
      ├───┼───┼───┤
      │ D │ E │ F │
      ├───┼───┼───┤
      │ G │ H │ I │
      └───┴───┴───┘

  井字格（带点）= J K L / M N O / P Q R      （形状完全一样，每格多一个点）

  X 形格（无点）= S T U V                    （上 / 左 / 右 / 下 四个三角形）
  X 形格（带点）= W X Y Z
```

  - 在线解密工具（把符号点出来就能出结果）：`https://www.metools.info/code/c90.html`、`http://www.hiencode.com/pigpen.html`。
  - 逐个对照后得到：

```text
thisispigpassword
```

- **第四步：按题目要求的格式提交**
  题目提示是 `flag{}`，所以最终提交：

```text
flag{thisispigpassword}
```

- 两个小坑：
  - 解出来的字母是**全小写**，照原样用就行（有些题会要求大小写，看清楚提示）；
  - 图片里的符号是**逐个字母**排列的，遇到不认识的形状别慌 —— 先找 `{` 和 `}`，它们是最好的锚点。

四、总结

- 这道题考的是两个知识点的组合：**base64 可以编码二进制（图片）** + **猪圈密码的图形对照**。
- 重要思维习惯：**base64 解码后如果得到乱码，不要以为解错了**，先看解出来的字节头部是什么 —— 是 `89 50 4E 47` 就是 PNG、`FF D8` 就是 JPEG、`PK` 就是 zip。很多人卡在第一步，就是因为一直在试图把图片的 base64 当文本读。
- 猪圈密码记两条规则就够：**先分"井字格 / X 形格"，再看"有没有点"**。9 个位置的顺序是"从左到右、从上到下"，X 形格的顺序是"上、左、右、下"。
- 同类变种要留意：不同题目可能用**镜像/旋转过的猪圈表**（比如圣堂武士密码），如果按标准表解出来是乱码，试试把表翻转或旋转再看 —— 或者用"已知明文"的思路先定几个字母，再反推整张表。
