Bugku CTF - 这不是md5 Writeup

一、题目信息

- 题型：Crypto（密码学）
- 题目：这不是md5
- 考点：十六进制（hex）编码识别与解码，以及"别被题目名带偏"的判断力

二、题目分析

- 题目描述就是一串字符：

```text
666c61677b616537333538376261353662616566357d
```

- 这串字符有两个容易让人误判的特征：
  - 全部由 `0-9` 和 `a-f` 组成；
  - 长度是 32+，看起来"很像 md5 摘要"。
- 但题目名字已经在提醒了：**这不是 md5**。
- 关键点在于：**md5 摘要是哈希值，不可逆**（只能靠撞库反查）；而十六进制编码是**可逆的**，两个十六进制字符就是 1 个字节，直接还原成字符即可。
- 再看密文开头，就很明显了：

```text
66 6c 61 67 7b ...
f  l  a  g  {   ...
```

`66 6c 61 67 7b` 对应的正好是 `flag{` —— 答案的前 5 个字符已经摆在明面上了。

三、解题步骤

- 第一步：确认它是十六进制。判断依据：字符集只有 `0-9a-f`，且长度是偶数（44 个字符 = 22 个字节）。
- 第二步：两两一组，按 ASCII 表还原成字符：

```text
66 6c 61 67 7b 61 65 37 33 35 38 37 62 61 35 36 62 61 65 66 35 7d
 f  l  a  g  {  a  e  7  3  5  8  7  b  a  5  6  b  a  e  f  5  }
```

- 得到 flag：

```text
flag{ae73587ba56baef5}
```

- 用 Python 一行就能解：

```python
# -*- coding: utf-8 -*-
h = '666c61677b616537333538376261353662616566357d'
print(bytes.fromhex(h).decode('utf-8'))
# flag{ae73587ba56baef5}
```

- 也可以用命令行工具：

```bash
# Linux / Git Bash：用 xxd 还原
echo 666c61677b616537333538376261353662616566357d | xxd -r -p

# 任何装了 Python 的机器都行
python -c "import codecs; print(codecs.decode('666c61677b616537333538376261353662616566357d', 'hex').decode())"
```

- 或者直接丢进在线工具：搜"十六进制转字符串 / hex 解码"（如 `hiencode.com/hex.html`），粘贴即可。
- 小提示：解出来的密文里花括号中的 `ae73587ba56baef5` 刚好是 **16 位十六进制**（32 位 md5 去掉两头后的一半长度），出题人就是故意做得"像 md5"来迷惑人。

四、总结

- 判断思路：**先看字符集，再想编码方式**。
  - 只有 `0-9a-f` + 长度为偶数 → 十六进制编码，直接 hex 解码；
  - 只有 `0-9a-f` + 长度 32 → 才可能是 md5（哈希，需要反查，不可逆）；
  - 只有 `A-Za-z0-9+/=` → base64；
  - 纯数字 → 可能是 ASCII 码或 Unicode 码位。
- 这道题的核心考点不是技术难度，而是**"先观察、再判断"**：题目名、字符集、长度这三个线索结合起来，就不会傻乎乎地拿它去 md5 解密网站上撞库了。
