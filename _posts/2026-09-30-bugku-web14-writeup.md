Bugku CTF - [+-<>] Writeup

一、题目信息

- 题型：Crypto（密码学）
- 题目：[+-<>]
- 金币：1　　分数：10
- 考点：Brainfuck 语言识别与执行

二、题目分析

- 题目名字就是 `[+-<>]`，题目描述是一大段只由 `+` `-` `<` `>` `[` `]` `.` `,` 这些符号组成的文本（中间夹杂空格和换行）：

```text
+++++ +++++ [->++ +++++ +++<] >++.+ +++++ .<+++ [->-- -<]>- -.+++ +++.< ++++[ ->+++ +<]>+ +++.< +++++ +++[- >---- ----< ]>--- ----- ---.< +++++ ++[-> +++++ ++<]> +++.< +++++ +[->- ----- <]>-- ----- -.--. ----. --.++ +++++ +.<++ ++++[ ->+++ +++<] >++++ +.++. <++++ ++[-> ----- -<]>- ----- ----. -.<++ +++++ [->++ +++++ <]>+. ----. ++++. <++++ +++[- >---- ---<] >---- .+.<+ +++++ ++[-> +++++ +++<] >++++ +++++ ++.<
```

- 这八个符号正是 **Brainfuck** 语言的完整指令集，所以题目本质就是"把描述里的代码跑一遍"：

```text
>  指针右移        <  指针左移
+  当前单元加 1    -  当前单元减 1
.  输出当前单元    ,  读入一个字符
[  当前单元为 0 时跳转到对应的 ]
]  当前单元不为 0 时跳回到对应的 [
```

三、解题步骤

- 最快的方法：把描述里的内容整段复制到 Brainfuck 在线解释器（例如 `https://ctf.bugku.com/tool/brainfuck`），运行后就能看到输出。

```text
Hello, World!
flag{0d86208ac54fbf12}
```

- 其中 `Hello, World!` 只是出题人顺手写的"彩蛋"，后面跟着的那一行才是真正的 flag。
- 也可以自己写解释器（顺便理解一下 Brainfuck 的运行机制）：

```python
# -*- coding: utf-8 -*-
code = '...'          # 把题目描述的内容粘贴进来，非 Brainfuck 字符会被自动过滤

code = ''.join(c for c in code if c in '><+-.,[]')

tape = [0] * 30000
p = i = 0
out = []
stack = []
br = {}
for j, c in enumerate(code):
    if c == '[':
        stack.append(j)
    elif c == ']':
        k = stack.pop()
        br[k] = j
        br[j] = k

while i < len(code):
    c = code[i]
    if c == '>':
        p += 1
    elif c == '<':
        p -= 1
    elif c == '+':
        tape[p] = (tape[p] + 1) & 0xFF
    elif c == '-':
        tape[p] = (tape[p] - 1) & 0xFF
    elif c == '.':
        out.append(chr(tape[p]))
    elif c == '[' and tape[p] == 0:
        i = br[i]
    elif c == ']' and tape[p] != 0:
        i = br[i]
    i += 1

print(''.join(out))
```

- 运行输出的最后一行就是 flag：

```text
flag{0d86208ac54fbf12}
```

四、总结

- 只需要认出"这八个符号 = Brainfuck"就够了，剩下的交给在线解释器，几十秒就能出答案。
- 这题和上一题 `ok`（Ook!）是同一类玩法：题目给一段"看起来很怪、但符号集合很固定"的代码，先判断语言，再找对应解释器执行，属于密码学 / 杂项里的入门题。
