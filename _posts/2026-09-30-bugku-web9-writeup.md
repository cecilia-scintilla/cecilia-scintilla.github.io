Bugku CTF - 瑞士军刀 Writeup

一、题目信息

- 题型：PWN
- 考点：远程连接（netcat / nc）、Linux 基础命令（ls、cat）

二、题目分析

- 题目描述只有一句 `ls`，并提示"启动场景"。
- "瑞士军刀"是 nc（netcat）的经典外号，它是网络工具里的万能工具，可以建立 TCP 连接、传文件、弹 shell。
- 题目描述给的 `ls` 就是提示：连上去之后先列目录，看看当前目录下有什么文件，再用 `cat` 把文件读出来。

三、解题步骤

- 点击"启动场景"，拿到形如 `ip:port` 的地址（例如 `160.202.254.160 15861`）。
- 在 Linux（Kali）终端用 nc 连接，格式是 `nc ip 端口`，注意 ip 和端口之间是**空格**，不要写成 `ip:端口`。

```bash
nc 160.202.254.160 15861
```

- 连上之后屏幕上不会回显任何提示符，这是正常的，直接输入命令并回车（这里其实就是把我们的输入当 shell 命令执行）：

```bash
ls
cat flag
```

- 执行 `cat flag` 后就能看到回显出来的 flag，把它提交即可。

四、总结

- 本题是把一个 shell 直接暴露在端口上，所以只要会用 nc 连接，再用最基本的 `ls` / `cat` 就能拿到 flag。
- 记住 `nc ip 端口` 这个格式，后面做 PWN 题（尤其是远程题）会经常用到。
